## 项目概要

三国背景回合制策略战棋 MAUI 游戏。核心逻辑在 `MauiApp.Game`（纯 C#），UI 用 SkiaSharp 自绘大地图与战斗方格，内容 JSON 驱动。

| 工程 | 说明 |
|------|------|
| `MauiApp` | MAUI 壳：页面、渲染、存档、内容加载 |
| `MauiApp.Game` | 规则引擎：大地图、战斗、AI、数值 |
| `MauiApp.Game.Tests` | 核心库单测 |

## 当前状态

- **里程碑**：M0–M20 已落地；**M21 部分**（像素贴图/头像、战场视口裁剪、演出对象池）
- **战场**：默认 50×50（`battleConfig`），程序化地形，固定格宽+相机拖拽
- **战斗 UX**：火焰纹章式「移动 → 行动菜单（攻击/猛击/详情/待机）」
- **战略规则**：出征必带武将、将令（每月一次）、主菜单 AI 难度、世界 AI 重写+月报
- **移动端**：SKTouch 拖拽/点击 + 双指缩放；相机 FitToBounds 自动适配
- **测试**：45 单测全过

## 当前焦点

- 用户验证：战斗贴图/头像、50×50 战场拖拽流畅度
